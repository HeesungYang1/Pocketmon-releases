## 0.9.3 피카츄 품질 표본

[v0.9.3 APK·체크섬·검증 범위](https://github.com/HeesungYang1/Pocketmon-releases/releases/tag/v0.9.3)

피카츄의 얼굴·귀·손발·등무늬·번개 꼬리와21본/8동작을 새로 제작해 필드·전투에 적용했습니다. 실제 광원과 주변/자체 그림자를 받는 셀 명암과 얇은 외곽선을 사용합니다.0.9.1~0.9.2의 게임용 트레이너·실제 빛/그림자 개선도 포함합니다. 기존 출현·능력·전투 규칙·저장 방식은 유지하며 내장 한국어 설명서는0.9.3입니다.

1,242개 자동 검사·PC/Blender 실제 렌더·Android14/x86_64 덮어설치/저장 보존·피카츄 터치 조우/공격·반격/필드 복귀·설명서를 확인했습니다. 기존 서명을 유지하며 공개 APK 전체 다운로드의 SHA-256을 대조했습니다. 피카츄는58,255삼각형/2재질로 이전보다 표시 비용이 늘었습니다. 물리 ARM64 성능·발열·멀티터치·오디오,30분 지속 실행과 최종 사용자 시각 수용은 미완료입니다. 전체151종/관동 제작 완료를 뜻하지 않습니다.

## 설치와 업데이트

Release의 APK를 내려받아 Android 설치 안내를 따르세요. 기기에서 요청하면 해당 파일 앱/브라우저에 '알 수 없는 앱 설치'를 허용합니다. APK는 프로젝트 전용 릴리스 키로 서명되어 있습니다. Play 스토어 배포본은 아닙니다.

업데이트할 때는 같은 서명의 새 APK를 기존 앱 위에 설치하세요. **앱을 삭제하거나 데이터를 지우면 저장도 삭제됩니다.** 업데이트 전 메뉴 → 저장 이동에서 코드를 복사해 외부 메모나 파일에 보관할 수 있습니다. 자동 업데이터와 클라우드 저장은 없습니다. 앱의 메뉴 → 사용설명서에서 한국어 안내를 오프라인으로 읽을 수 있습니다.

현재0.9.3은 저장 형식2를 사용합니다. 기존 형식1은 변환하지만 형식2 저장으로 구버전 APK에 돌아가는 것은 지원하지 않습니다.

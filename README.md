## 설치와 업데이트

Release의 APK를 내려받아 Android 설치 안내를 따르세요. 기기에서 요청하면 해당 파일 앱/브라우저에 '알 수 없는 앱 설치'를 허용합니다. APK는 프로젝트 전용 릴리스 키로 서명되어 있습니다. Play 스토어 배포본은 아닙니다.

업데이트할 때는 같은 서명의 새 APK를 기존 앱 위에 설치하세요. **앱을 삭제하거나 데이터를 지우면 저장도 삭제됩니다.** 자동 업데이터와 클라우드 저장은 없습니다. 앱의 메뉴 → 사용설명서에서 한국어 안내를 오프라인으로 읽을 수 있습니다.

이 저장소는 README만 추적하고, 릴리스 자산에는 APK와 SHA-256만 게시합니다. 원본 소스·서명 키·개인정보·QA 자료는 포함하지 않습니다. APK 내부 실행 코드와 리소스는 추출 가능하며 비공개 소스가 이를 숨기지는 않습니다.
